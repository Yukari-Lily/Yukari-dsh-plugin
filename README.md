# Yukari 插件合集

DeepSeek Harness（dsh）自用插件合集，一个侧边栏面板装下十一个组件。

| 组件 | 作用 |
|---|---|
| 会话 | 按工作区浏览、归档、删除会话；子智能体会话折叠在主对话下，勾选主会话会连带勾选子会话 |
| 会话回撤 | 用户消息下方一个回撤按钮：把对话原地退回该消息，并可一起还原此后的工具文件改动（不新建分支、不改日志） |
| 站点 | 静态网页一键发布到 `/p/<名字>/`，可设置自己的访问域名前缀 |
| 文件 | 浏览工作区全部文件；单文件下载、任意勾选文件夹打包下载；预览交给 DSH 自己的文件预览 |
| 约束 | 全局与工作区的约束：`$DSH_HOME/rules.md` 与 `<工作区>/rules.md`，写进系统提示词首尾，面板内编辑、下一轮生效；可从 AGENTS.md / CLAUDE.md 导入 |
| 预设 | 自定义智能体预设：以已有预设为模板新建，再改元数据、人格提示词与能力行；内置预设只读，复制一份就能改 |
| 代理 | Shadowsocks 出站代理，支持一次导入多个节点（ss:// / 订阅 / Clash），选一个使用并测速；配置或节点失效时自动恢复直连 |
| GitHub | 持久化 GitHub 推送令牌：面板验证、检查仓库写权限、清除；装好凭据助手后任意会话直接 `git push` |
| 无限制模式 | 额外注册一个对话模式：首段契约 + 尾部锚点 + 改写宿主劝退句 + 拒绝自动重试，标准模式不受影响 |
| 无头浏览器 | 给智能体用的 Chromium 浏览器工具（`browser_*`），自动准备 Chrome 与缺失的运行库 |
| 状态 | dsh 版本检查、更新与重启 |
