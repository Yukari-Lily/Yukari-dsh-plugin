# Yukari 插件合集

自用插件合集

| 组件 | 作用 |
|---|---|
| 会话 | 按工作区管理会话 |
| 会话回撤 | 回撤对话与工具文件改动 |
| 站点 | 发布静态站点 |
| 文件 | 浏览、预览与下载工作区文件 |
| 约束 | 管理全局与工作区约束 |
| 技能 | 管理 DSH 技能 |
| 预设 | 管理自定义智能体预设 |
| 代理 | 管理 Shadowsocks 代理 |
| GitHub | 管理 GitHub 推送凭据 |
| 无限制模式 | 提供独立的无限制对话模式 |
| 无头浏览器 | 提供 Chromium 浏览器工具 |
| 状态 | 检查、更新与重启 dsh |
